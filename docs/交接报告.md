## 1. 项目定位

Fire Loop（火环）是一个装在个人 Windows 11 电脑上的用户态常驻 agent。

目标：

- 系统能直接调用她：命名管道、fireloop 协议、文件右键；
- 她能感知系统：文件、剪贴板、前台窗口事件；
- 能用 API 的地方直接调 API，不模拟人点击。

项目边界：

- 个人自用，不考虑对外发布；
- 不做安装包、代码签名、自动更新、多用户分发；
- 不做 Windows 服务、内核驱动、替换 explorer、登录凭据提供者；
- 不把旧项目小鲸鱼的代码、记忆、UI、图标带进来；
- 旧项目只作为历史，不在新仓库里引用。

## 6. 完整项目路线

当前已经完成 M1a、M1b、M2。后续建议：

### M3 事件驱动主动任务

目标：

- 事件不只记录，而是按规则触发任务；
- 文件、剪贴板、前台窗口、通知、网络、空闲；
- 规则白名单、去抖、去重、每小时配额；
- 事件风暴只记录，不烧模型；
- 托盘/最小界面（如果需要）。

验收：

- 丢文件进监控目录，自动生成任务；
- 剪贴板变化可按规则触发；
- 前台窗口变化只记录上下文，不乱执行；
- 所有事件先落 event_dispatch，命中规则才调模型；
- 闲时 0 token。

### M4 API 能力替换

目标：

- IFileOperation 替代资源管理器点击；
- IAudioEndpointVolume 控制音量；
- WmiMonitorBrightnessMethods 控制亮度；
- Task Scheduler COM 管理计划任务；
- App Paths/Shell.Application 启动程序；
- 浏览器优先 CDP/无头，只有自绘页面才 UIA/截图。

验收：

- 每个能力换完真跑一次；
- 不弹窗、不模拟鼠标；
- 失败有回退。

### M5 可选服务化

只在确实需要“登录前/无用户会话也能跑”时评估。

如果做：

- 用户会话进程持有全部状态和手眼；
- 服务只做无界面长任务；
- 不是服务负责想、代理负责看；
- 记忆只由一侧写。

否则不做。

### 暂不规划

- 内核驱动；
- 替换 explorer；
- 登录凭据提供者；
- COM Shell Extension；
- 对外发布、代码签名、自动更新。

## 8. 当前可用的验证命令

在 D:\ds植入式：

```powershell
$env:PYTHONPATH = "$PWD\src"

python -m fireloop.agent
python -m fireloop.cli ping
python -m fireloop.cli task "测试"
python -m fireloop.cli file "D:\资料\a.txt"
python -m fireloop.cli uri "fireloop://task?text=%E4%BD%A0%E5%A5%BD"

python -m unittest discover -s tests -v
python tests\acceptance\run_m1a_acceptance.py
```

默认验收覆盖 M1a + B1 + B2 + M2，使用隔离管道、隔离互斥体、临时数据目录，不杀正在运行的 agent，不联网。

完整验收加桌面事件：

```powershell
python tests\acceptance\run_m1a_acceptance.py --enable-desktop-events
```

会短暂改动剪贴板和前台窗口，跑之前确认桌面可被测试。

结果窗口真测：

```powershell
python tests\acceptance\run_m1a_acceptance.py --enable-result-window
```

跨用户 SID：

需要先建 fl_test 标准用户并设置 FL_TEST_PASSWORD，再按 docs\验收.md 执行。
